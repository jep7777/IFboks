Firmware for an ESP32-based interface box for a smart shower system. 

This project was developed as part of a semester-long group project in an electronics engineering degree.

The interface provides a button-controlled LCD menu for configuring water and energy limits, monitoring shower data, and displaying warnings. It communicates with the shower box over UART.

The project was built using PlatformIO and the Arduino framework. The SerLCD library was used to communicate with the LCD screen.
